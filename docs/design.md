# Best GUI：初期設計

WebView・HTML・CSS・JavaScript を使用しないネイティブ GUI を目指す。
現時点では実験段階であり、世界最軽量・1ms 未満を達成したとは主張しない。

2026-09-08：Rust の `no_std` 描画コア、macOS/AppKit 接続、Metal 矩形描画、
操作用デモ、CPU/入力計測、GPUピクセル検証を実装。文字は暫定 AppKit ラベル。
その後の選定で winit + wgpu を主実装として追加。直接 Metal 版は比較用。
追加実装：HarfRust + ttf-parser + Windfoil方式WGSLで英字と日本語を描画。
2026-09-09：高度な編集アプリを検証用に実装し、角丸、境界、クリップ、文字キャッシュ、
安定ID、フォーカス、ポインターキャプチャをライブラリへ追加。
Graphy組み込みは利用者の指示で対象外。2026-09-09にSlugからWindfoilへ移行。
起動と制限は [README](../README.md) を参照。

## 性能の定義

「軽さ」は単一指標にしない。リリースビルドの実行ファイルサイズ、依存ライブラリ、
起動時間、プロセス常駐メモリ、GPU メモリ、待機時 CPU 使用率を別々に報告する。
OS フレームワークを除いたサイズと、実プロセスの負荷を区別する。

暫定目標はウォーム状態でのイベント受信から GPU コマンド投入まで p99 < 1ms。
GPU 実行時間・描画先の取得待ち・OS イベント滞留・表示待ちは個別に計測し、
合算したエンドツーエンド遅延を CPU 処理時間で代用しない。
60Hz の更新間隔は約 16.67ms、120Hz は約 8.33ms なので、
一般的なディスプレイで入力から発光まで常時 1ms 未満は保証できない。

条件は端末、OS、解像度、DPI、電源状態、ビルドフラグ、文字数、可視要素数、
フォント、キャッシュ状態を記録。中央値・p95・p99・最大値・サンプル数を報告。
初回フォント読込・シェーダー生成を含むコールド時も別途評価する。

## 構成

- コア：Rust を採用（[言語選定記録](language-decision.md)）。利用側が用意する連続メモリに描画命令を格納。既存の C++20 コードは比較用の初期実験。
- OS 層：ウィンドウ、イベント、IME、クリップボード、アクセシビリティ。
- 描画層：主実装は wgpu のネイティブバックエンド。直接 Metal 版を比較用に保持する。
- UI：ID で状態を保持し、変更したレイアウトと描画データを更新。
- 文字：シェーピングとアウトライン描画を分離。日本語、結合文字、
  フォールバック、双方向文字を描画アルゴリズムだけで解決しようとしない。

再描画はイベント・変更・アニメーションがあるときだけ要求する。
GPU の処理待ちを無制限に積まず、使用中のバッファは完了まで再利用しない。
透過を含む painter's order を守り、バッチ化によって重なり順を変更しない。
ウォーム状態での自前ヒープ確保ゼロを目指す。OS/ドライバ内の確保は別に評価する。

## 文字描画の比較

[Slug の公開参照実装](https://github.com/EricLengyel/Slug) は
GPU で二次 Bézier 輪郭を評価するシェーダーを提供している。
完成した文字組みエンジン一式とは区別し、移植時に元コードのライセンスと帰属表示を保持する。

[Windfoil](https://github.com/texel-org/windfoil) は winding integral による
解析的 AA と行バンドを用いる。公開実装の実行基盤は WebGPU だが、
採用する場合はアルゴリズムをネイティブシェーダーへ移植する。
作者のベンチマークでは縮小時に Slug が速い傾向があり、Windfoil の一律優位は前提にしない。

両方式へ同じグリフ・位置・クリップ・色を渡し、各方式に適したバンド構造を生成する。
静的な小サイズ文字はカバレッジアトラスも比較基準にする。
直接曲線描画が全ケースで最速とは仮定せず、速度・メモリ・可読性で選択する。

検証シーン：12–16px の日本語本文、長文スクロール、1万可視グリフ、
拡大縮小、回転、複雑な漢字、フォント切替、混在 DPI。
輪郭の穴・接線・退化曲線・極小サイズと三次曲線の変換誤差も検証する。

## 実装順

1. 固定容量の描画リストと CPU マイクロベンチマーク。
2. ネイティブウィンドウ、Metal 描画、入力から投入までの計測。
3. HarfRustの文字組み結果からグリフ輪郭を取り出し、Slug方式で描画（旧実装）。
4. Windfoilへ移行し、解析的box-filter AAと極小グリフ用ink profileを実装（実装済み）。
5. ドックレイアウト、スクロール、キーボード操作（検証デモで実装）。
6. IME変換中表示、アクセシビリティ、仮想リスト、複数フォント。

初期マイクロベンチマークは矩形命令の構築のみ。GUI 全体の性能を意味しない。
